# Procédure — Assistant public et contenus

## Périmètre autorisé

L’assistant peut répondre uniquement à partir de contenus pratiques validés :

- localisation et accès aux cabinets ;
- fonctionnement des demandes de rendez-vous ;
- documents et préparations validés ;
- horaires et coordonnées approuvés ;
- informations générales déjà publiées ;
- orientation vers une page du site.

## Périmètre interdit

L’assistant ne doit pas :

- poser un diagnostic ;
- interpréter un examen ou un résultat ;
- recommander ou modifier un traitement ;
- évaluer personnellement un symptôme ;
- garantir qu’une situation n’est pas urgente ;
- inventer une réponse absente de la base validée.

## Traitement des réponses inconnues

1. Classer la question comme `À ANALYSER`.
2. Ne pas créer automatiquement une nouvelle réponse publique.
3. Regrouper les questions similaires sans conserver d’identité inutile.
4. Préparer une proposition de réponse pratique.
5. Faire valider par Lucia tout contenu médical ou sensible.
6. Publier uniquement après validation et versionner le changement.

Réponse publique recommandée :

> Je n’ai pas trouvé de réponse fiable dans les informations validées du cabinet. Consultez la FAQ ou contactez le secrétariat. Je préfère ne pas inventer une réponse.

## Publication d’une nouvelle règle

Avant publication, vérifier :

- source de l’information ;
- formulation compréhensible ;
- absence de conseil médical individualisé ;
- validation de Lucia lorsque nécessaire ;
- date et auteur de la modification ;
- test de la réponse dans le simulateur ;
- absence de contradiction avec une règle existante.

## Revue périodique

Fréquence proposée : `À VALIDER`.

La revue doit couvrir :

- questions sans réponse ;
- refus médicaux ;
- alertes d’urgence ;
- réponses obsolètes ;
- liens cassés ;
- changements d’horaires, de lieux ou de règles ;
- statistiques sans données identifiantes.

## Retrait immédiat

Une réponse doit être dépubliée immédiatement si elle est erronée, ambiguë, obsolète ou susceptible d’induire une décision médicale inappropriée.
