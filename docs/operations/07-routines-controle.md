# Procédure — Routines de contrôle

## Ouverture quotidienne

- vérifier que le portail est accessible ;
- consulter les nouvelles demandes ;
- identifier les rendez-vous à confirmer ;
- vérifier les annulations et changements reçus ;
- contrôler les alertes de l’assistant ;
- repérer les incidents ou actions en attente de Lucia.

## Pendant la journée

- traiter les demandes selon leur ordre et leur niveau de priorité validé ;
- mettre à jour les statuts après chaque action ;
- éviter les notes parallèles non tracées ;
- signaler immédiatement toute situation inhabituelle ;
- vérifier le cabinet associé avant chaque confirmation.

## Fermeture quotidienne

- aucune demande nouvelle ne doit rester sans statut ;
- les rappels non aboutis doivent comporter une trace ;
- les rendez-vous du lendemain doivent être vérifiés ;
- les décisions en attente de Lucia doivent être regroupées ;
- les incidents ouverts doivent être transmis au responsable ;
- aucune donnée sensible ne doit rester affichée ou imprimée sans nécessité.

## Revue hebdomadaire

- demandes reçues, confirmées, refusées, sans réponse et en doublon ;
- rendez-vous annulés, reportés et patients absents ;
- questions inconnues de l’assistant ;
- erreurs ou réponses à retirer ;
- comptes utilisateurs et accès à modifier ;
- incidents de la semaine ;
- contenus, horaires ou consignes devenus obsolètes ;
- actions nécessitant une validation de Lucia.

## Revue mensuelle proposée

Fréquence définitive `À VALIDER`.

- vérifier les utilisateurs actifs ;
- examiner le journal d’audit selon les droits disponibles ;
- tester les parcours essentiels avec des données fictives dans l’environnement adapté ;
- vérifier les liens, coordonnées et règles publiées ;
- confirmer que les procédures correspondent toujours au fonctionnement réel ;
- archiver la revue avec date, responsable et actions décidées.
