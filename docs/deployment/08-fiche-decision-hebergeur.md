## Questions contractuelles

- Où les données et sauvegardes sont-elles hébergées ?
- Quels sous-traitants interviennent ?
- Quelles garanties sont contractuellement proposées ?
- Comment les incidents sont-ils signalés ?
- Comment récupérer toutes les données en quittant le service ?
- Quel délai est prévu pour supprimer les données après résiliation ?
- Quel support est inclus ?
- Quels coûts apparaissent au-delà des quotas ?

## Critères éliminatoires proposés

- absence de sauvegarde exploitable ;
- impossibilité de séparer préproduction et production ;
- secrets obligatoirement stockés dans le code ;
- base publiquement exposée sans restriction adaptée ;
- absence de TLS ;
- impossibilité d’exporter ou restaurer les données ;
- conditions contractuelles incompatibles avec le projet ;
- coût non maîtrisable ou insuffisamment documenté.
