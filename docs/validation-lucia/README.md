# Dossier de validation des contenus — Cabinet Lucia

## Objectif

Ce dossier prépare les contenus du site avant l’échange avec Lucia. Il ne publie aucune information médicale ou organisationnelle non confirmée.

Chaque élément est classé dans l’un des états suivants :

- **Présent dans le projet** : information déjà utilisée dans le site actuel, à confirmer avant publication définitive.
- **Proposition éditoriale** : texte préparé pour gagner du temps, à accepter, corriger ou supprimer.
- **Information attendue de Lucia** : donnée qui ne peut pas être décidée sans elle.

## Méthode de validation

Pour chaque bloc, Lucia pourra répondre avec l’une des mentions suivantes :

- `VALIDÉ`
- `À CORRIGER : ...`
- `À SUPPRIMER`
- `À REMPLACER PAR : ...`

## Limites

- Les textes médicaux restent soumis à la validation professionnelle de Lucia.
- Les horaires, durées, prescriptions, cabinets disponibles et règles de rendez-vous ne sont pas supposés.
- Les informations juridiques et la politique de confidentialité seront traitées dans une tâche distincte.
- Les photos et visuels restent à fournir ou à approuver.
