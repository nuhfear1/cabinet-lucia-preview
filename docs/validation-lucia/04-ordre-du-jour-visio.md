# Ordre du jour — Visio de validation avec Lucia

## Durée cible

45 à 60 minutes.

## Objectif de la réunion

Prendre toutes les décisions nécessaires pour transformer les propositions actuelles en contenus définitifs, sans demander à Lucia de rédiger elle-même le site.

## Préparation avant l’appel

Gary prépare :

- le site ouvert sur les pages principales ;
- la matrice des validations ;
- les propositions de textes ;
- la liste des photos et documents attendus ;
- ce compte rendu prêt à compléter.

Lucia est invitée à avoir à portée de main :

- ses diplômes, titres et informations professionnelles ;
- les horaires des deux cabinets ;
- les coordonnées à publier ;
- les règles de rendez-vous ;
- la liste des personnes qui auront accès au portail ;
- les photos disponibles.

## Déroulé proposé

### 1. Présentation rapide du projet — 5 minutes

Montrer :

- la page d’accueil ;
- la page de la docteure ;
- les consultations ;
- les cabinets ;
- le parcours de demande de rendez-vous ;
- l’assistant pratique ;
- l’espace professionnel.

Décision attendue : confirmer que le périmètre général correspond au projet attendu.

### 2. Présentation professionnelle — 8 minutes

À valider :

- nom professionnel exact ;
- titre à afficher ;
- biographie ;
- diplômes ;
- expérience ;
- associations professionnelles ;
- numéro RPPS ;
- engagements mis en avant ;
- informations à ne pas publier.

### 3. Consultations et examens — 12 minutes

Pour chaque motif :

- nom exact ;
- description ;
- durée ;
- cabinet disponible ;
- nécessité d’une ordonnance ;
- documents à apporter ;
- préparation spécifique ;
- cas qui doivent être traités directement par téléphone.

### 4. Rendez-vous et secrétariat — 10 minutes

Décisions attendues :

- demande de rendez-vous ou réservation immédiate ;
- délai de réponse du secrétariat ;
- jours et horaires de traitement ;
- règles d’annulation et de modification ;
- gestion des doublons ;
- gestion des demandes urgentes ;
- message transmis au patient après sa demande.

### 5. Cabinets et accès — 7 minutes

Pour chaque cabinet :

- adresse exacte ;
- repères d’accès ;
- stationnement ;
- transports ;
- accessibilité ;
- téléphone ;
- horaires ;
- actes réalisés sur place ;
- photos à utiliser.

### 6. Assistant pratique — 7 minutes

Valider :

- les sujets autorisés ;
- les réponses pratiques ;
- les refus médicaux ;
- les messages d’urgence ;
- les coordonnées communiquées ;
- les questions qui doivent être transférées au secrétariat.

### 7. Accès professionnels — 5 minutes

Décider :

- qui aura un compte ;
- rôle de chaque personne ;
- adresse e-mail utilisée ;
- niveau d’accès ;
- personne chargée de créer ou supprimer les comptes.

### 8. Photos, documents et prochaines étapes — 5 minutes

Recenser :

- photo portrait ;
- photo en consultation ;
- photos des deux cabinets ;
- diplômes et titres ;
- coordonnées ;
- horaires ;
- documents utiles aux patients ;
- date cible de retour des éléments.

## Règle de conduite pendant l’appel

Pour chaque sujet, choisir immédiatement l’un des statuts suivants :

- `VALIDÉ`
- `À CORRIGER`
- `INFORMATION À FOURNIR`
- `DÉCISION REPORTÉE`
- `HORS V1`

## Sortie attendue de la réunion

À la fin de l’appel, Gary doit disposer :

- des décisions prises ;
- de la liste des informations manquantes ;
- du nom de la personne responsable de chaque envoi ;
- d’une date de retour ;
- des éléments à intégrer immédiatement ;
- des sujets reportés après la V1.
